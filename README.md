# CV_Filter

A collection of core computer vision utilities for image filtering, edge detection, segmentation, and more.

## Project Structure

- `core/`
  - `__init__.py`: Package initializer
  - `convolution.py`: Convolution operations
  - `edge_detection.py`: Edge detection algorithms
  - `filters.py`: Image filtering functions
  - `image_io.py`: Image input/output utilities
  - `pipeline.py`: Image processing pipelines
  - `segmentation.py`: Image segmentation methods

## Usage

Import the desired modules from the `core` package in your Python scripts:

```python
from core import filters, edge_detection, segmentation
```
